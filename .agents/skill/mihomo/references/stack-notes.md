# Mihomo Stack Notes

These notes are derived from the live stack files:

- `docker-proxy/compose.d/16-mihomo.yml`
- `docker-proxy/mihomo/config.yaml`
- `docker-proxy/mihomo/proxy-providers/local/proxies.yaml`
- `script/template/mihomo.config.yaml.template`

## Enablement

Mihomo is optional. The installer and compose launcher default `ENABLE_MIHOMO=false`; `run-compose.sh` skips `16-mihomo.yml` unless the value is truthy. The installer wizard can toggle `ENABLE_MIHOMO`, and `script/modules/02_env.sh` only renders `/opt/docker-proxy/mihomo/config.yaml` when Mihomo is enabled.

`URI_MIHOMO` is generated by the installer and exported through the env templates. `MIHOMO_SECRET` is generated as a hex secret and rendered into the config from `script/template/mihomo.config.yaml.template`; the rendered file is chmodded to `0600` when possible.

## Compose Service

`16-mihomo.yml` defines one service:

- container name: `mihomo`
- image: `metacubex/mihomo:latest`
- restart: `unless-stopped`
- config mount: `../mihomo:/root/.config/mihomo`
- network: `traefik-proxy`
- hardening: `no-new-privileges=true`
- internal controller/dashboard port exposed to Traefik: `9090`

No host ports are published by the compose fragment. Public access is only through Traefik labels.

## Traefik Routing

The public dashboard/controller path is:

```text
https://${WEBDOMAIN}/${URI_MIHOMO}/ui/
```

Traefik forwards to service `mihomo-ui-svc` on container port `9090`, with healthcheck path `/ui/`.

Middleware chains:

- `mihomo-chain`: `bouncer@file`, rate limit, admin security headers, strip prefix, compression.
- `mihomo-static-chain`: same as above plus `mihomo-basic-auth`; used for `/${URI_MIHOMO}/ui` static dashboard paths.
- `mihomo-manifest-chain`: no BasicAuth; used for dashboard manifest files under `/${URI_MIHOMO}/ui/`.
- `mihomo-ui-slash-chain`: BasicAuth plus redirect from `/${URI_MIHOMO}/ui` to `/${URI_MIHOMO}/ui/`.
- `mihomo-root-chain`: BasicAuth plus redirect from `/${URI_MIHOMO}` or `/${URI_MIHOMO}/` to the Zashboard setup URL with `secondaryPath=/${URI_MIHOMO}`.

Routers, highest to lowest priority:

- `mihomo-ui-manifest` priority `974`: `PathRegexp('/${URI_MIHOMO}/ui/.*manifest(.webmanifest|.json)$')`.
- `mihomo-ui-slash` priority `973`: exact `Path('/${URI_MIHOMO}/ui')`.
- `mihomo-ui-static` priority `972`: `PathPrefix('/${URI_MIHOMO}/ui')`.
- `mihomo-ui-root` priority `971`: exact root path with or without trailing slash.
- `mihomo-ui` priority `970`: catch-all `PathPrefix('/${URI_MIHOMO}')`.

Preserve the strip-prefix middleware when changing paths. Mihomo serves `/ui/` internally, while clients arrive through the random `${URI_MIHOMO}` prefix.

## Runtime Config

`docker-proxy/mihomo/config.yaml` is the runtime baseline mounted into the container. The installer template is a shorter seed that uses the same core controller/DNS/proxy-provider structure but leaves most routing as `MATCH,INTERNET`.

Current runtime highlights:

- `allow-lan: true`
- `bind-address: "*"`
- `mixed-port: 7890`
- `secret: ${MIHOMO_SECRET}` in the repo file/template, rendered on install
- `external-controller: 0.0.0.0:9090`
- `external-ui: zashboard` in the runtime file; template uses `/zashboard`
- `external-ui-url`: latest Zashboard release archive
- fake-IP DNS on `0.0.0.0:1053`, `respect-rules: true`, IPv6 enabled
- proxy providers:
  - local file provider at `./proxy-providers/local/proxies.yaml`
  - sample HTTP providers at `./proxy-providers/subs/provider1.yaml` through `provider3.yaml`
- provider health checks use `https://cp.cloudflare.com/generate_204`
- service groups include `AUTO`, `Zablok. servisy` (Cyrillic in the live file), and per-service selectors for YouTube, Discord, Twitch, Reddit, Meta, Spotify, Speedtest, Telegram, Steam, CDN, Google, GitHub, AI, Twitter, and TikTok
- rule providers mostly use MetaCubeX `meta-rules-dat`, plus project-specific `zxc-rv` and `legiz-ru` rule sets
- final fallback is `MATCH,DIRECT`

`docker-proxy/mihomo/proxy-providers/local/proxies.yaml` currently contains only the top-level `proxies:` key. Do not assume local nodes exist.

## Security Notes

Never print real `MIHOMO_SECRET`, provider URLs, proxy credentials, or subscription contents. Redact as `<redacted>` when discussing a live config.

The controller binds to `0.0.0.0:9090` inside the container so Traefik can reach it. Keep public exposure behind the current Traefik auth and middleware chain. The controller API itself relies on `secret`; the static UI path is additionally protected by BasicAuth.

`mixed-port: 7890`, DNS `listen: 0.0.0.0:1053`, `allow-lan: true`, and `bind-address: "*"` are broader listener choices. Before widening network attachment or publishing host ports, document who can reach these listeners and whether authentication is configured.

QUIC is rejected in the live rule set to force HTTP/2 over TCP and avoid some transparent-proxy bypass behavior.

## Operational Notes

Use the compose wrapper for service operations:

```bash
docker-proxy/compose.d/run-compose.sh validate
docker-proxy/compose.d/run-compose.sh restart mihomo
docker-proxy/compose.d/run-compose.sh logs mihomo
```

For config syntax validation, prefer:

```bash
mihomo -t -d docker-proxy/mihomo -f docker-proxy/mihomo/config.yaml
```

If the binary is not installed locally, say so and still run `git diff --check` plus any compose validation available in the repo.
